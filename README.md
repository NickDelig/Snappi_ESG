# Snappi ESG Banking Prototype

A mobile-first banking experience exploring how everyday spending could connect to ESG information and customer rewards. The prototype was created by our team for Snappi's Climathon and received first place.

## What it demonstrates

- A banking dashboard with payment, savings, and loan account cards.
- An ESG score and tier system tied to illustrative merchant scores.
- Snappies rewards, transaction insights, and a tree that grows with rewards.
- Interactive payment and redemption flows backed by in-memory sample data.
- A presenter mode for adding sample purchases and showing how the prototype responds.

This is a portfolio prototype, not a banking product. Balances, rates, merchant ESG scores, rewards, and transactions are illustrative sample data. Payments and redemptions do not move money or issue real rewards.

## Run locally

Requirements: Node.js and npm.

```sh
npm ci
npm run dev
```

Vite prints the local development URL when the server starts. Other available scripts are `npm run build`, `npm run preview`, and `npm run lint`.

## Technology

React, TypeScript, TanStack Start and Router, Vite, and Tailwind CSS.

## Project context

This was a team project developed for Snappi's Climathon, where it received first place. Lovable was used as a development tool during the prototype process.
